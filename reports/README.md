# Lensight Diagnostic Reports & Artifacts

This directory stores diagnostic dashboards, metric exports, and visual attribution overlays generated by `lensight` benchmark and demonstration scripts.

---

## Directory Contents

| Artifact | Source Script | Description |
|---|---|---|
| `resnet_fashion_diagnosis.html` | `examples/train_and_diagnose_resnet.py` | Interactive failure-mode diagnosis dashboard for ResNet-18 on Fashion-MNIST with filter chips, search, and confusion clustering. |
| `resnet_fashion_gradcam.png` | `examples/train_and_diagnose_resnet.py` | High-resolution Grad-CAM visual explanation overlay on a real test garment. |
| `resnet_fashion_metrics.json` | `examples/train_and_diagnose_resnet.py` | Structured diagnostic telemetry exported for automated CI/CD quality gates. |
| `audit_report.html` | `examples/dataset_audit_demo.py` | Comprehensive multi-tab dataset audit dashboard (Duplicate Clusters, Cross-Label Contradictions, and Train/Test Leakage). |
| `dataset_audit_manifest.json` | `examples/dataset_audit_demo.py` | JSON manifest detailing per-sample duplicate status and cluster survivor assignments. |
| `fashion_eda_report.html` | `examples/dataset_eda_demo.py` | Standalone exploratory data analysis report (class balance, blur, exposure defects). |
| `model_diagnosis_report.html` | `examples/real_world_demo.py` | End-to-end model diagnosis report with calibration remediation. |
| `diagnosis_metrics.json` | `examples/real_world_demo.py` | Evaluation metrics and calibration parameters. |
| `demo_gradcam.png` | `examples/real_world_demo.py` | Sample Grad-CAM overlay comparison. |
| `gradcam_overlay.png` | `examples/quickstart.py` | Quickstart explainer overlay. |
| `diagnosis_report.html` | `examples/full_diagnosis.py` | Synthetic model diagnosis report. |

---

## Viewing Reports

All `.html` reports are completely self-contained with **zero external CSS/JavaScript dependencies**. Double-click or open any HTML file in any modern web browser to interact with it offline.
