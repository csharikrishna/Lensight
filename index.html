from lensight.eda import DatasetAuditor, check_leakage, DatasetSanitizer

# 1. Audit training dataset for duplicate clusters and conflicting labels
auditor = DatasetAuditor(class_names=["cat", "dog", "fox"])
audit_report = auditor.audit(train_loader, threshold=0)
print(audit_report.summary_text())
audit_report.save_html("reports/audit_report.html")

# 2. Check for train/test data leakage
leakage = check_leakage(train_loader, val_loader, threshold=0)
print(f"Leaked validation samples: {leakage.leaked_count} ({leakage.leakage_rate:.1%})")

# 3. Non-destructive in-memory sanitization (zero disk copy!)
clean_train_subset = DatasetSanitizer.clean_subset(train_dataset, audit_report)
# Ready for training with zero disk files touched!

FAQ

Frequently Asked Questions

Does Lensight force OpenCV or Pandas?

No! Lensight runs strictly on PyTorch, NumPy, Pillow, and Scikit-Learn. All perceptual hashing, blur variance kernels, and interactive dashboards use pure NumPy and Pillow. The entire wheel package is under 80 KB.

Does Temperature Scaling reduce accuracy?

Never. Temperature scaling rescales logits by scalar $T > 0$. Because scaling is strictly monotonic, $\arg\max_k (z_k / T) = \arg\max_k z_k$. Your top-1 classification predictions and accuracy remain 100% mathematically invariant.

How is duplicate clustering 15x faster?

Legacy tools use nested Python loops comparing pairs one-by-one. Lensight bit-unpacks 64-bit perceptual hashes into NumPy arrays and uses a 256-element bitwise XOR popcount lookup table running in C/SIMD vector registers.

Does it support Vision Transformers (ViT)?

Yes. Lensight includes create_vit_reshape_transform(), which reshapes 1D patch tokens into 2D spatial feature maps, enabling Grad-CAM, HiResCAM, Grad-CAM++, and EigenCAM on ViT, DeiT, and DINO models seamlessly.
