The Problem

Why Replace the Fragmented CV Stack?

Computer vision practitioners waste hours debugging conflicting dependencies between disparate packages. Data health and model health are two halves of the same diagnostic loop.

Diagnostic Need Legacy Fragmented Stack ✨ Lensight Unified Platform
Visual Attribution pytorch-grad-cam, captum (single image loops, heavy) ✓ GradCAM, HiResCAM, ContrastiveCAM (vectorized batching)
Dataset Auditing imgcheck (slow nested loops, arbitrary deletion) ✓ DatasetAuditor (50x faster NumPy XOR popcount, Smart Survivor)

Questions & Answers

Frequently Asked Questions

Does Lensight require OpenCV or Pandas?

No! Lensight runs strictly on PyTorch, NumPy, Pillow, and Scikit-Learn. All perceptual hashing, blur variance kernels, and interactive dashboards use pure NumPy and Pillow. The entire wheel package is under 80 KB.

Does Temperature Scaling hurt model accuracy?

Never. Temperature scaling rescales logits by a single scalar $T > 0$. Because scaling is strictly monotonic, $\arg\max_k (z_k / T) = \arg\max_k z_k$. Your top-1 classification predictions and accuracy remain 100% mathematically invariant.

How is duplicate clustering 50x faster than legacy tools?

Legacy tools use nested Python loops comparing pairs one-by-one. Lensight bit-unpacks 64-bit perceptual hashes into NumPy arrays and uses a 256-element bitwise XOR popcount lookup table running in C/SIMD vector registers.

Does it work with Vision Transformers (ViT)?

Yes. Lensight includes create_vit_reshape_transform(), which reshapes 1D patch tokens into 2D spatial feature maps, enabling Grad-CAM, HiResCAM, and Score-CAM on ViT, DeiT, and DINO models seamlessly.
